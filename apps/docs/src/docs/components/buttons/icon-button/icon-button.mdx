<section id="section-usage">
## Usage

### Variants

Like Button, IconButton supports filled and transparent variants. Use transparent for toolbar actions or subtle controls.

<ComponentPlayground code={doc.usageExamples[0].code} layout={doc.usageExamples[0].layout} scope={iconScope} />

### Colors

Apply a color to match the action context. Primary for main actions, neutral for general-purpose, and error for destructive ones.

<ComponentPlayground code={doc.usageExamples[1].code} layout={doc.usageExamples[1].layout} scope={iconScope} />

You can also pass any hex color and seedui will automatically generate the full shade scale for hover, focus, and active states.

<ComponentPlayground code={doc.usageExamples[2].code} layout={doc.usageExamples[2].layout} scope={iconScope} />

### Button & Icon sizes

Two props control how big an IconButton is. <code>size</code> sets the button's padding and a matching icon size. Small works well in dense toolbars, medium is the default, and large is suited for prominent standalone actions.

<ComponentPlayground code={doc.usageExamples[3].code} layout={doc.usageExamples[3].layout} scope={iconScope} />

Use <code>iconSize</code> (in pixels) when you need a different icon size than the preset gives, for example to fit an IconButton inside a smaller component. The padding from <code>size</code> stays the same, so the button's total size is the padding plus the icon.

<ComponentPlayground code={doc.usageExamples[5].code} layout={doc.usageExamples[5].layout} scope={iconScope} />

### Disabled

A disabled IconButton is visually muted and non-interactive. Use it when the action is temporarily unavailable.

<ComponentPlayground code={doc.usageExamples[4].code} layout={doc.usageExamples[4].layout} scope={iconScope} />
